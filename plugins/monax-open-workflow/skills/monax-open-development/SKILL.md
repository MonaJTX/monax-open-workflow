# 通用开发

先按 [上下文](../../rules/context.md) 找到当前约束，再使用 [开发流程](../../rules/development.md)。已有同范围批准可复用，明确只读则保持只读；[任务边界](../../rules/boundaries.md) 拥有授权判断。

设计、UI、架构或性能任务按需读 [设计与审查](../../rules/design-review.md)。游戏任务转到 [游戏规则](../../rules/game-development.md)，不默认读取视频模块。

验证真实调用和配置路径，用 [验证规则](../../rules/verification.md) 说明证据与缺口。满足完成条件后交付，必要接续写入已有项目 owner，不自动扩大为全局维护。
