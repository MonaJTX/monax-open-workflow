# AI 视频

按 [上下文](../../rules/context.md) 找到当前项目的脚本、素材和已接受基线。读 [视频入口](../../rules/ai-video.md)，然后只进入本阶段的导演、Prompt 或生产主文件。

使用 [Brief](../../templates/video-brief.md)、[镜头包](../../templates/shot-package.md) 或 [台账](../../templates/production-ledger.md) 时按当前项目填写；模板和虚构例子不是实际素材或生成回执。

写 Prompt 时区分静态冻结瞬间、分镜运动设计与动态执行；核对实际上传输入，DesignOnly 分镜不假称已上传。批量镜头保持各自完整并检查邻镜差异。

生成与后期使用当前宿主实际可用的工具，核对规格、素材许可和授权范围。上传、扣费、重试和发布按 [生产规则](../../rules/ai-video-production.md) 与 [任务边界](../../rules/boundaries.md) 执行。交付 Prompt 不代表媒体已经生成，技术检查不等于用户审美接受。
