# 项目记忆

按 [上下文](../../rules/context.md) 查当前项目及所选子项目索引，再读匹配的正文。现行事实来自当前 owner 和实际实现，历史摘要用于定位来源。

记录或接续按 [记忆规则](../../rules/memory.md)：保留目标、当前对象、状态、证据、剩余工作、下一步与失效条件，优先更新已有 owner。通用方法与项目事实分开，不能写进插件缓存或其他项目。

按 [验证规则](../../rules/verification.md) 区分验证、验收和未知状态。更新发现索引，核验团队分发方式；能在本机看到不等于别人能继承。原始材料和私人信息不要自动提升为公共规则。
