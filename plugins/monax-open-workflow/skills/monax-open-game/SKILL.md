# 游戏开发

读 [上下文](../../rules/context.md) 和 [游戏规则](../../rules/game-development.md)。先核验产品目标、引擎版本、运行场景和真实配置，不套用示例业务值。

新增能力按 [通用开发](../../rules/development.md) 查已有实现与可复用方案。预约/异步完成、缓存、字体或资产适配任务只读 [游戏方法](../../rules/game-methods.md) 中匹配部分。

验证产品规则到 caller、场景、资产和平台的实际路径。视觉验收和目标平台验证按 [验证规则](../../rules/verification.md) 分开记录。用户只要分析时不修改代码或资产。
