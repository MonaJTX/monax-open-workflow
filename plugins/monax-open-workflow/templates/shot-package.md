# 镜头包（空白模板）

仅供填写，不能直接付费提交。关联方法：[导演设计](../rules/ai-video-directing.md)、[Prompt](../rules/ai-video-prompts.md)。

## 导演卡

镜头 ID、脚本原句/beat、第一认知、叙事锚点：待填写。
入口、主体/空间、主次动作、景别/机位、相机路径、关键帧、结束状态/出口：待填写。
时长、时间线角色、相邻差异、专属失败条件：待填写。

## 静态图 Prompt

填写一帧确定瞬间：叙事任务、主体姿态与空间、景别机位、光线材质、文字/素材保护、失败条件。不要放动作时间线。

## 导演分镜 Prompt

填写关键帧、主体动作、相机路径、结束状态及图面说明边界。

## 视频 Prompt

完整填写真实上传绑定、逐段动作、运镜、结束状态、素材/文字/声音边界、质量与失败条件；不得用“同上”替代内容。

## 版本与检查

设计状态、输入绑定、工具上限、邻镜衔接、用户审阅、是否允许提交、剩余问题：待核验。
