# 素材、提交与验收

Rule ID：VIDEO-PRODUCTION-01。真实素材进入输入/交付链，或发生付费/不可幂等提交时，读取本文件的适用部分。完全虚构且只写 Prompt 的任务不要求生成虚假费用或素材证据。

## 生产路线与事实边界

明确 AI-Native、AI+Deterministic Composite、Post-Only 或 Hybrid，记录哪些内容可重绘、必须保真、是否允许后期覆盖及采用决定。不能在执行失败后静默改成另一条路线、降低清晰度标准或删除必须出现的素材。

每项必须保真的素材登记 ID、相对路径、hash、尺寸/方向/比例、用途、权限状态、上传范围、目标覆盖等级与镜头绑定。hash 只证明字节版本，不证明版权、肖像、隐私许可、真实性或上传权。

| 覆盖等级 | 意义 |
| --- | --- |
| Evidence-P0 | 已提供或上传 |
| Evidence-P1 | 画面中出现 |
| Evidence-P2 | 可辨认素材身份 |
| Evidence-P3 | 关键人物、标题、Logo 或事实可读 |
| Evidence-P4 | 指定文字逐字或像素级核对通过 |

这些等级与“P0 质量阻断”无关。用户要求目录中全部素材时，先枚举数量、类型及用途；生成后逐项核对身份、数量、可读性和遮挡。联系表可压缩传输，不能替代源清单或证明单项可读。

只有付费但没有真实素材时，素材身份、保真等级和同空间检查标 N/A，只执行提交、费用、下载和结果检查。真实素材仅在后期覆盖时，检查比例、像素/文字、位置、遮挡和时间绑定，不虚构 AI 空间融合证据。

## 容量与输入职责

检查“揭示＋回正稳定＋阅读＋退出/转场＋必要动作/运镜”是否能放进镜头时长。每项高可读性素材需有可定位稳定时段。容量不足先决定减载、拆镜、延长或改路线，不能用更多 Prompt 字数硬塞。

风格参考负责光色材质，主体母版负责身份外观，真实证据负责事实，动作参考负责运动；职责重叠、失败图回流或输入过多时先重分工。平台允许上传的数量不等于模型能稳定遵循的数量。

真实素材进入生成空间时先确定物理身份：实体纸页/展框、屏幕/投影或全画幅影像。分别核对透视、厚度或发光、受光、反射、遮挡、景深、人物视线和接触位置；不要给屏幕套纸张规则，也不要强迫后期覆盖伪装成真实物体。

## 一次提交的预检

核对同一版本的镜头 ID、模型和规格、实际上传清单/顺序/hash、UTF-8 Prompt 回显/hash、路线、预计消耗及有效授权。任一不一致时停止提交。hash 正确不代表设计正确。

默认一次提交、NoAutoRetry。已有明确批次或预算授权时按其确切范围执行；没有覆盖重试的授权时，不因平台失败、下载损坏或生成不满意再次扣费。超时后先查询原任务状态，不直接创建重复任务。

记录任务回执、费用和停止条件。同类设计失败达到项目阈值时回到容量、输入职责或空间设计；下一轮说明主要修改变量，不持续追加形容词抽卡。

## 下载与分层验收

区分 PlatformAccepted、GenerationSuccess、DownloadComplete 和 DecodePass。下载核对数量、大小、容器/流、时长、分辨率、帧率和 hash，完整解码后再进入视觉检查。平台显示成功不等于媒体交付成功。

分别记录：

- TechnicalPass：完整文件、可解码及规格。
- CompositionPass：主体、空间、角色和镜头关系。
- EvidencePass：目标覆盖等级、身份、比例、文字与数量；不适用标 N/A。
- UserAccepted：用户明确接受当前版本。
- FinalAccepted：项目必需检查均通过且无当前阻断。

视觉检查对照源素材与视频全过程，检查首帧、关键动作、结尾、角色漂移、手部/物体变形、文字和声音。只看联系表不能证明整段连续动作；自动检查不能替代审美决定。

## 台账、候选与失败复盘

用 [production-ledger.md](../templates/production-ledger.md) 记录输入、Prompt、输出、版本、状态、检查、用户决定及下一动作。分别归因到设计路线、输入/Prompt、模型履约、平台/编码/下载；不要把所有问题归给模型。

失败图默认不回流参考；只有单一职责已验证且无污染时才显式解禁。保留正式基线、候选、Rejected 和 Superseded 的关系；不删除现有素材或覆盖已接受版本来简化目录。

后期导出核对实际时间线、字幕/Logo、音轨、响度目标、画幅、编码和最终时长。是否发布是独立动作；交付本地文件不代表已发布。
