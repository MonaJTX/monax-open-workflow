# 游戏与资源方法索引

Rule ID：GAME-METHOD-01。以下为条件方法，不是现成组件。具体算法、预算和参数由项目决定，未在接收者项目验证。

## 资产适配与批量推广

先辨认原模型、Prefab、子层级、材质、碰撞和绑定的职责，保留手调姿态、比例与动画关系。外层适配优先于破坏原资产；不能为迁就算法擅自改已接受画面。先用代表样件验证，再按显式范围批量应用，记录例外；检查通过不自动代表用户接受全部样件。

## 预约与快照提交

队列、异步资源或动态调度中，分开稳定身份、目标槽位、预约、实际到达和显示完成。业务释放依据业务约定的事件，装饰动画不能自行增加业务门禁。

未开始的预约可按规则重排，已开始的行程保留承诺；晚到回调核对会话版本。多入口不能继续用单个前缀游标替代已曝光集合。动态提案只改未承诺部分，在快照上验证，提交前再次比较版本与前提；失败或过期不提交业务变更，临时资源仍须释放。

检查唯一占位、不丢不重、取消、重开、暂停、倍率变化和过期完成。局部合法续解不能证明任意后续操作成功，更不能证明产品难度或商业效果。

## 派生缓存

列出决定结果的输入、源资源指纹、实例身份和生命周期。输入变化、资源替换、对象复用及禁用恢复时明确失效策略。只缓存语义相同的计算，不跳过必要积分或动作采样。

不匹配时安全重算或拒绝使用，使原因可观察；禁止调整真实相机和资源来适配旧缓存。比较结果正确性和性能收益，覆盖微小输入变化、导入设置变化、销毁重建与保存重开。

## 字体交付

从正式文案、配置、场景及运行生成文本提取字符集合；外部昵称、服务端文案、组合字符另定策略。检查真实字体 Unicode 映射、随包引用和 fallback，不能以字体名字、文件大小或开发机系统回退作证。

复用成熟字体检查/子集工具，保留字源与许可，保护已接受的字形和字距。子集命令成功后仍核对缺字集合；静态映射覆盖不能证明组合排版、渲染和视觉居中。默认检查不改字体，目标环境核验换行、裁切和字重。

## 生命周期、动效与交付闭包

确认业务完成、动画完成、音效结束与资源释放的不同边界。对象池复用需清理旧回调、订阅和状态；异步返回核对存活对象及版本。应用暂停和场景切换不能重复发奖或遗留资源。

资源交付从运行引用追到构建产物：字体、Shader、配置、远程资源和预生成内容都要覆盖。编辑器存在不等于目标包包含；转换或平台构建需要的预生成资源必须在相应构建前准备，并检查正式加载路径。
