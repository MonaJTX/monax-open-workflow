# 三层 Prompt 与批次质量

Rule ID：VIDEO-PROMPT-01。项目目标和导演设计分别见 [ai-video.md](ai-video.md)、[ai-video-directing.md](ai-video-directing.md)。

## 静态图：一个确定瞬间

静态图锁定风格、主体关系、材质、空间、光线、构图和素材比例。写明这一帧的叙事任务、主体位置/姿态、景别与机位、前中后景、字幕留白、文字和素材保护要求。

每张图只有一个可被摄影机捕捉的瞬间。不能同时描述动作前、中、后，不写逐秒时间线或推拉摇移过程。动作可以有方向，但必须落实成一套物理状态，例如“手刚接触物体”。静态图确认后才将其作为动态化基线。

角色/主体母版负责身份、服装、体型、比例和材质，不默认承担群像构图。风格参考只负责风格，不应偷带另一个项目的角色、布局、机位或品牌。复杂小字、准确 Logo、网址和证书优先考虑后期，具体路线由项目决定。

## 导演分镜：动作与相机路径

分镜说明关键帧、动作顺序、主体调度、视线/接触关系、运镜路径和结束状态。它不是最终视频画面。按需要用连续格、轨迹示意或分阶段视图，不强制固定格数。

每镜必须选择一种输入角色：

- **DesignOnly**：供设计和审阅，不上传视频工具。将动作、关键帧和运镜完整转译进动态 Prompt；不得写模型能看到未上传的图。
- **UploadInput**：核对工具能力、素材权限及文字/箭头污染风险后，才加入上传清单；注明它只控制动作与运镜，最终画面不能出现其文字、边框和轨迹。

用途未定或图面污染风险未处理时使用 DesignOnly。上传清单、Prompt 和实际提交必须一致；分镜用途判断不自动授予上传权限。

## 视频 Prompt：执行已经设计好的动作

每段正文完整包含：实际参考素材及职责、主体、场景、按时间拆分的动作、相机运动、结束状态、真实素材保护、文字/声音边界、质量和失败条件。

按实际段长拆时间，写清谁动、怎么动、到哪里、何时结束；避免只写“电影感运镜”。静态图锁定画面，动态 Prompt 执行导演轨迹，不在动态阶段重新发明人物和场景。

只有实际上传的素材才可写“参考已上传”。素材尚未生成时明确这是待绑定草稿；不能把草稿伪装成可付费提交包。工具字数或参考槽位不足时，保留事实、动作、运镜和边界，先压缩形容词；仍超限则重新设计。

## 可复制镜头包

每镜包含导演卡、上传清单、静态 Prompt、分镜 Prompt、动态 Prompt。每段可复制正文都独立包含必要约束，不能假设工具会读取总控文件、另一个聊天或工程目录。

交付两个及以上正式镜头 Prompt 时，逐镜检查自包含、相邻差异和后段细节衰减。禁止“同上”“其余一致”替代必需字段。字符合规、标题齐全和文件存在不证明质量。

无法保持质量时明确本批镜头范围与下一批起点，剩余项标 Pending；不要用提纲和占位块冒充整批成品。空白模板可以保留待填字段，但必须清楚标为模板。

## 声音、字幕与音乐

项目先决定视频模型是否负责正式声音。未选定时可建议把正式音乐、旁白、字幕和精确品牌声效放后期，视频生成仅保留约定的环境/动作音；用户选择音画联合生成时按其路线核验，不强制改路线。

BGM Prompt 写整体风格、情绪曲线、配器、速度感、旁白让位、总时长与限制。仅当工具确实支持时间轴编曲时才指定分段时间；视频镜头时长不等于配乐总时长。每轮候选尽量只改一个主要变量，保存参数与采用结论。

不想要的风格词可能仍影响某些模型；主 Prompt 用正向目标，独立 negative 字段存在时将禁用风格放那里。没有配对生成证据时，这是待验证风险，不能宣称某个词一定导致某种结果。

## 工具限制与版本

模型版本、时长、画幅、分辨率、参考输入和音频能力在实际生产前查当前工具与官方资料。上传槽位上限不是稳定内容容量。不要在公共方法中固化某个收费套餐、模型版本或所有项目的段长。
