# 虚构示例：纸船出发

目标：用两个镜头表达“放手出发”，展示三层 Prompt 的职责。全部为虚构设计，无品牌、真人或真实素材。没有生成图片、视频或音乐，没有提交任务或消耗费用。

设计：16:9、柔和手工微缩风格、浅蓝纸船、青绿色浅溪、暖侧光。镜头 01 为 5 秒放船，镜头 02 为 7 秒漂行；12 秒是本例设计值，不是方法默认值。视频模型、分辨率和最终声音在实际生产前另选并核验。

本例采用 PromptHandoff，分镜为 **DesignOnly**，正式字幕和音乐放后期。生成阶段只允许约定水声和动作音，不要音乐、人声、旁白或画面文字。

## 文件

- [两镜头完整 Prompt](shots.md)：导演卡、静态、分镜与动态草稿。
- [示例台账](ledger.md)：明确未生成、未绑定、未提交和未验收。

视频正文仅在对应静态图已生成、审阅并实际上传后可使用。目前文件名是计划槽位，不是已存在素材。上传前必须填入真实文件与 hash，核验工具规格和授权。

## 试用任务

> 只读检查这两个镜头的衔接，以及 Prompt 有没有把未上传的分镜图当输入。

预期：核对纸船颜色、形状、朝向、漂移方向、镜头 01 出口和镜头 02 入口；确认分镜 DesignOnly，视频 Prompt 只依赖对应静态图且完整描述运动；指出当前仍是未绑定草稿，不声称可直接提交。

> 我想让第二镜更有出发的感觉，只改第二镜的导演设计与 Prompt，不生成。

预期：保留第一镜已设定身份和出口，在第二镜调整运镜或空间变化，更新相应层与台账；不上传、不付费、不虚构产物。
