# 纸船出发：两镜头设计稿

状态：Draft / InputsUnbound。下列静态与分镜文本可作为虚构设计输入；动态正文必须在该镜静态图实际生成、审阅、上传并绑定后才可提交。所有素材名为计划相对路径。

## 镜头 01：松手

导演卡：脚本 beat 为“把纸船放入溪流”。第一眼看见指尖和浅蓝纸船的接触。浅溪从画面左侧流向右侧，船头朝右。一只戴米白手套的手从左上轻扶船尾；主动作是松开，次动作是手退出左上。近景、低机位，结尾船随水向右离开手，镜头继续跟随，不静止定格。设计 5 秒，下一镜接漂行。

输入：静态图待生成，计划槽位 `assets/shot-01-static.png`；分镜 DesignOnly，不上传；没有真实素材或母版文件。失败条件：纸船变色、船体散开、手变形、漂移方向反转或输出文字。

### 静态图 Prompt

```text
生成一张16:9手工微缩风格的电影静帧。青绿色浅溪中有一只浅蓝折纸船，纸张折痕清晰，船头朝画面右侧。一只戴米白布手套的手从画面左上伸入，两指轻扶船尾，船底已经接触水面；这是尚未松手的单一瞬间。
低机位近景，焦点落在船尾与指尖的接触处，纸船主体位于中间偏左，右侧留出清晰水道。暖侧光从左后方照亮纸边，背景石块柔焦，水面有细小波纹。只有一只手和一只船，不出现人物脸部、文字、字幕、Logo、边框或多格拼图。纸船结构完整，手指数量和接触关系自然。
```

### 导演分镜 Prompt（DesignOnly）

```text
制作一张仅供导演审阅的三格连续分镜图，16:9横向版面，表现5秒放纸船动作。统一浅蓝折纸船、米白手套、青绿色浅溪与左后暖侧光，船头始终朝右。
第一格：低机位近景，两指轻扶已接触水面的船尾。第二格：手指放开，手朝左上撤离，船开始向右漂。第三格：手已离画，纸船保持结构并继续向右漂行。
格间用少量箭头说明手向左上退出、船向右漂、相机平缓向右跟随。标注只是导演说明，不属于最终画面；本图不会上传视频模型。不要增加第二只船、人物脸、品牌或无关场景。
```

### 视频 Prompt（静态图绑定后使用）

```text
请参考本次上传的镜头01静态图生成5秒16:9视频，用该图锁定浅蓝折纸船、米白手套、青绿色浅溪、微缩材质、低机位和左后暖侧光。没有上传导演分镜图，动作完全按以下文字执行。
0—1.5秒：手指缓慢松开船尾，船保持朝右且船底持续接触水面。
1.5—3秒：手向左上退出画面，纸船随溪流向右漂，不能被手抛起。
3—5秒：相机低位平缓向右跟随，让船保持画面中央，水纹自然分开；结尾纸船仍向右运动，保留接下一镜的漂行相位，不突然静止。
保持单只纸船的颜色、折痕和完整形状，不增加人物或其他船。只保留细小水声与必要动作音，不生成音乐、人声、旁白或口型。画面无文字、Logo、箭头、分镜线和边框。失败条件为手变形、船散开、漂移方向反转或突兀切镜。
```

## 镜头 02：穿过叶影

导演卡：beat 为“纸船继续向未知处漂行”。入口承接同一浅蓝纸船向右运动，手已经离画。主动作是沿溪流漂过上方叶影；机位由近景缓慢拉远到中景，露出前方水道。船从中心漂向右侧出口，相机不改变航向。设计 7 秒，以持续出画收束，不新增文字或人物。

输入：静态图待生成，计划槽位 `assets/shot-02-static.png`；需对照镜头01已确认船体，实际参考图绑定待定；分镜 DesignOnly，不上传。失败条件：船型漂移、方向反转、叶子变成实体障碍或末尾无动机停滞。

### 静态图 Prompt

```text
生成一张16:9手工微缩风格静帧。青绿色浅溪中央有一只浅蓝折纸船，船头朝画面右侧，纸张折痕清晰、船体完整；这一帧表现已经独立漂行的状态，没有手和人物。
低位近景，船位于中间，右侧水道开阔。上方画外植物把柔和叶影投在水面前方，叶片不接触纸船。左后暖侧光照亮纸边，岸边小石和苔藓构成柔焦背景。船的外观应与本片已确认基线一致，基线需在实际生成前另行绑定。画面无文字、Logo、箭头、边框和拼图，不新增第二只船。
```

### 导演分镜 Prompt（DesignOnly）

```text
制作一张仅供导演审阅的三格连续分镜图，16:9横向版面，表现7秒纸船漂行。所有格保持同一浅蓝折纸船、船头朝右、青绿色浅溪、左后暖侧光和手工微缩材质，不出现手或人物。
第一格：低位近景，船在画面中央向右漂。第二格：相机平缓后移，船经过水面柔和叶影，更多前方水道进入画面。第三格：中景里船沿原方向接近右侧边缘，继续运动并将自然出画。
箭头只示意向右漂行与相机后移。叶影是光影而非阻挡物。分镜为DesignOnly，不上传模型，不成为最终画面。无品牌、第二只船或无关景物。
```

### 视频 Prompt（静态图绑定后使用）

```text
请参考本次上传的镜头02静态图生成7秒16:9视频，锁定浅蓝折纸船、朝右船头、青绿色浅溪、手工微缩材质和左后暖侧光。本次没有上传导演分镜图，完全按以下动作与相机路径执行。
0—2秒：承接已经进行中的漂行，纸船从画面中央平稳向右前进，不能重新经历放船准备动作。
2—5秒：纸船穿过水面柔和叶影，保持结构与颜色，相机低位平缓后移到中景，露出前方水道。叶影不是实体障碍，不挤压或包裹纸船。
5—7秒：相机保持中景，纸船沿原方向继续漂向画面右边并自然出画，以水流延续结束，不突然冻结或反转。
只出现一只纸船，不出现手、人物或其他船。只有轻微水声，不生成音乐、旁白、人声或口型。无文字、字幕、Logo、箭头、分镜线和边框。失败条件为船型漂移、逆流、叶片变成障碍、突兀切镜或无动机停滞。
```
