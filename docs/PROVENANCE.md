# 来源与适配

本版是 MonaX 方法的独立公开整理，不携带原仓库历史或外部私有文件引用。日期：2026-11-05，版本：0.1.0。

| 公开内容 | 来源方法类别 | 本版处理 |
| --- | --- | --- |
| 初始化、预检、只读 Hook 和基础测试 | 已有独立游戏开发分享包 | 复用可移植 Python 实现，更换包身份，扩展通用/视频模板与测试 |
| 上下文、记忆、边界与验收 | 通用协作、项目记忆与证据分层 | 重新组织为自包含主文件，去除个人环境依赖 |
| 通用开发和设计审查 | 需求、编码、设计、性能和审查流程 | 保留复用优先、最小完整设计及适度验证 |
| 游戏方法 | 游戏运行绑定、资源与条件经验 | 保留适用条件，不宣称已跨项目验证的组件 |
| AI 视频 | 视觉生成、导演层及项目模板 | 保留三层 Prompt、动作出口、素材保真、费用和验收边界 |
| 示例与公开发行工具 | 本版新增 | 使用虚构文本/代码，工具无网络功能 |

本版整理者未引入第三方项目代码或媒体。许可沿用已存在分享包的 MIT，版权署名使用 MonaX contributors，不含个人姓名或邮箱。

这是选取并重写方法后的发行版本，未承诺与原系统逐文件等价。未打包原有机器专属路由器、完整状态驾驶舱、实时安装验收和历史场景库；本包以按需 Markdown 路由、独立接入与结构检查提供自包含使用方式。

以后更新先比较相关公开 owner 与源方法变化，选择性适配、重新审阅和测试；不要整体复制私人仓库，也不要用旧源文件直接覆盖社区贡献。

- [OpenAI 插件格式与本地 marketplace](https://developers.openai.com/plugins/build/plugins)
- [Hook 事件与信任](https://learn.chatgpt.com/docs/hooks)

上述资料用于核对打包方式，不代表官方认可或宿主运行验收。
