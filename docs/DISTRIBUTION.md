# 公开范围与发行边界

只发布 `distribution-files.json` 明确列出的文件。它覆盖规则、空白模板、虚构示例、技能、可选插件清单、工具、测试、许可证和公共维护说明。ZIP 不携带任何 Git 历史。

排除：真实业务项目、原始记忆/聊天、个人习惯、账号与凭据、本机配置、插件安装缓存、私人运行回执、实际素材、下载 URL、临时目录与历史归档。公开方法可以来自实践，但项目身份和业务值不能随方法进入发行包。

`tools/check_distribution.py` 检查显式清单、文件类型、UTF-8、相对引用、常见机器路径和凭据模式。它是启发式检查，不能证明所有个人信息已被自动识别。新增内容仍需人工审阅，尤其是示例、测试、截图与复制的日志。

`tools/package_release.py` 先检查再打包，只读清单内源文件，拒绝已有目标，生成 ZIP、逐文件 hash 与归档 hash。不会访问原工作流、安装插件、初始化 Git 或上传网络；包更新后需重新打包。

公开仓库从经过审核的文件清单建立独立的 Git 历史。维护者更新时应核对实际提交内容与发行清单是否一致。

本包源码可按 MIT 发布到代码托管站点。代码仓库公开与提交到某个宿主的公共插件目录是不同动作，后者须按届时平台规则单独核验。
